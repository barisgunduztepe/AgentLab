## Sonuç ve kapsam

Agent konuşmayı koşuya ait yerel mesaj dizisinde tutar. Fake, OpenAI Responses, Gemini Interactions ve retry sarmalayıcısı `complete({ messages, tools, signal })` kullanır. Provider içindeki previous/pending konuşma kimlikleri ve calculator'a özel şema kopyaları kaldırıldı. Calculator JSON nesnesini doğrular; tanım ve çalıştırma yetkisi ayrıldı. Üç araç çalıştırma sınırı ve mevcut prompt metinleri korunur.

İptal, model HTTP isteği ve retry beklemesi dahil uçtan uca taşınır. Başlamış deney `failed/cancelled` olarak kaydedilir; başlanmamış ikinci karşılaştırma koşusu oluşturulmaz. SSE `start` koşu promise'ini bekletmez; reader cancel bekleyen model isteğini durdurabilir. Terminal olay ve kayıt tekliği, timer/listener temizliği ve geç dönen sonuçlar test edilir.

Model olaylarına finishReason ve usage eklendi. Nihai deney çıktısı yalnız type/text kalır. History v3 korunur; eski v1/v2/v3 kayıtlarına metadata uydurulmaz. Yazmada özel alanlar atılır; okumada bilinmeyen alanlar reddedilir. Model olayları prompt/yanıt/araç içeriği/çağrı kimliği/ham SDK hatası içermez; mevcut görev, nihai çıktı ve handoff çıktısı sözleşmeleri korunur.

## Sorunlar, sınırlar ve sapmalar

- İlk sandbox test denemeleri, Vitest cache dosyalarının rename işleminde EPERM ile testler yüklenmeden başarısız oldu. Aynı testler onaylı yerel yürütmede geçti. Bu başarısız denemeler başarılı test sayısına dahil edilmedi.
- Sandbox localhost'una tarayıcı erişemedi. Fake/geçici history sunucusu yerel yürütmede açılarak UI doğrulaması tamamlandı.
- Geliştirme sunucusu terminal çıktısında `UNKNOWN: unknown error, write` görüldü. UI işlemleri ve üç geliştirme history kaydı başarılıydı. Production build ve production UI kontrolünde tekrar gözlenmedi; kök neden teşhis edilmedi.
- Yeni dependency, gerçek API çağrısı, push, merge, rebase veya geçmiş değiştirme yapılmadı. Ana framework ve provider API'leri korundu. Tasarım kapsamından sapma yok.
- Geçiş köprüleri ilk commit'te kaldı; ikinci commit'te eski provider metotları ve calculator string girdisi kaldırıldı. Fake fixture girdileri ölçüm alanlarını atlayabilir; `complete()` her zaman açık finishReason ve usage döndürür.
- OpenAI tool şeması `strict: false` ile taşınır; ortak şema alt kümesindeki opsiyonel alanların API tarafından sessizce zorunluya çevrilmesi önlenir. Çalıştırma öncesi doğrulama araçtadır.
- Eski uygulamanın yeni history ölçüm alanlarını/iptal kodunu okuması garanti edilmez. Yeni sürüm eski kayıtları okur.
- Usage yalnız yanıt alınan denemenin bildirdiği tüketimdir; başarısız retry tüketimi ve maliyet hesaplanmaz. Eksik toplam türetilmez.
- İptal kooperatiftir; senkron calculator ortasında zorla kesme ve uzak sunucunun üretim/ücretlendirmesini durdurma garantisi yoktur.
- Özel reasoning replay/opaque signature gerektiren modeller destek kapsamı dışında. Durdur düğmesi v0.9.4'te; yerel/OpenAI uyumlu adaptör ve canlı doğrulama v0.8.4'te.
