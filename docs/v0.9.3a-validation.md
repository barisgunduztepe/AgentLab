## Durma ve onaylı düzeltme kaydı: rapor sözleşmesi

`src/agent/critic-report.ts:35`, C1–C3 durumunda enum kontrolünde `String(value.verdict)` kullanıyordu.
Bu, string dışındaki bazı JSON değerlerini string'e dönüştürerek kabul ediyordu.
Dosya yazmayan, guard'lı yerel parser çağrısında:

```json
{"verdict":["no_issue"],"issues":[]}
```

girdisi reddedilmedi. Gözlenen sonuç:

```json
{"accepted":true,"verdictType":"object","isArray":true,"result":{"verdict":["no_issue"],"issues":[]}}
```

Beklenen: rapor geçersiz; normal runner yolunda `invalid_report`, güvenli `unknown` arızası, otomatik repair/retry yok.
Parser yanlış tipte verdict döndürüyordu; geçici DTO'nun ilan edilen tipine aykırıydı.
O andaki testlerin yeşil olması bu negatif örneği kapsamıyordu.

Görev dosyası: **“Tasarımla çelişki, kapsam taşması (4 commit'e sığmama) veya sözleşme sorunu bulursan durup raporla; uydurma, sessiz ek kapsam yok.”**
Bu yüzden ilk tur durduruldu; onay gelmeden parser değiştirilmedi veya C4 commit edilmedi.
